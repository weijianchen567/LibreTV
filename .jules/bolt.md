## 2025-02-23 - Express Static Config & Async Read Optimization
**Learning:** In Express request handlers (like `renderPage` used for static routes `/` and `/player.html`), synchronous file reads (`fs.readFileSync`) block the Node.js event loop, degrading performance under concurrent load. Furthermore, CPU-bound operations (like computing SHA-256 hashes of static configuration values) inside the request handler cause unnecessary overhead on every page load.
**Action:** When serving static files that require token replacement, use asynchronous file reads (`fs.promises.readFile`). If injecting static config values (like environment variables) into files, pre-calculate expensive derivations (like hashes) at startup using top-level `await` so they can be reused across requests.
