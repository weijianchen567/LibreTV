## 2024-10-05 - Optimize CPU-bound operations in Node.js server startup
**Learning:** CPU-bound operations like cryptographic hashing (e.g., `crypto.createHash('sha256')`) can block the Node.js event loop. When these operations are dependent on static configurations (like environment variables), they can be precalculated once at startup using ES modules' top-level `await`. This prevents redundant, blocking calculations during individual request handling, significantly improving request throughput and response time.
**Action:** Always look for opportunities to shift static, CPU-intensive computations (such as configuration hashing or complex string parsing) out of request handlers and into the module initialization phase, taking advantage of top-level `await` if available in the environment.
