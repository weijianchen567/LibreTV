## 2024-05-19 - [Avoid Sync I/O and Redundant Computation in Express Route Handlers]
**Learning:** Using `fs.readFileSync` and constantly re-hashing static configurations (like passwords) on every request blocks the Node.js event loop, preventing the server from handling other requests during that time. In an Express backend that handles many requests or large files, this leads to significant performance degradation.
**Action:** When rendering templates or handling static files, always use asynchronous methods like `fs.promises.readFile`. Additionally, for any configuration values that remain static during the application's runtime (like passwords from environment variables), compute their expensive operations (like SHA-256 hashes) exactly once at startup using top-level `await` and store the result, caching it for all subsequent requests.
