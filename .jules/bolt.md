## 2024-05-24 - [Node.js Sync I/O Blocked Event Loop]\n**Learning:** The Express backend was using `fs.readFileSync` in the primary route handler for rendering the React HTML string, creating a significant bottleneck for concurrent requests by blocking the single Node.js thread.\n**Action:** Use asynchronous I/O (`fs.promises.readFile`) for file operations within request handling cycles to ensure non-blocking execution in Express applications.
