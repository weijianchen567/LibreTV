## 2024-05-18 - Pre-computing Hashes and Async File I/O
**Learning:** In Node.js server applications, blocking the event loop with synchronous operations like `fs.readFileSync` or performing redundant, computationally expensive operations like hashing static configuration values (e.g., passwords) on every request can significantly degrade performance and concurrency. The backend here uses ES Modules and supports top-level await.
**Action:** Always prefer asynchronous file reading (`fs.promises.readFile`) over synchronous alternatives (`fs.readFileSync`) in request handlers. For static configuration values that need expensive processing (like hashing), perform the computation once at server startup (utilizing top-level await if available) and cache the result, rather than recalculating it on every request.
