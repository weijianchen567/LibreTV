## 2026-10-08 - Asynchronous File Reads and Precomputed Hashes\n**Learning:** Node.js file system APIs like `fs.readFileSync` can significantly block the event loop in high-throughput Express.js routes. Moving synchronous file reads to `fs.promises.readFile` and offloading statically known intensive operations (like SHA-256 hashing configs) to application startup with top-level await reduces per-request latency.\n**Action:** Use `fs.promises` over `fs` sync methods inside Express route handlers and pre-calculate any static configuration data at startup using top-level await.
